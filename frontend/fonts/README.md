# Manrope

`Manrope-ExtraBold.woff2` is the unmodified Manrope ExtraBold (weight 800) font used for the OKO wordmark.
It is bundled by Vite and served locally by Django along with the interface fonts below.

- Source: [googlefonts/manrope](https://github.com/googlefonts/manrope/blob/6f81ebecdf65e4463b798cc07b16a4f8d5216917/fonts/webfonts/Manrope-ExtraBold.woff2)
